# 新闻通知类模板规范

## 定位

用于报名开放、课程上新、覆盖区域和人群通知。核心目标是让用户在 3 秒内看懂：
“哪里、开放什么、适合谁、下一步去哪里了解”。

## 参考基线

- 参考目录：`assets/新闻通知类模板/`
- 参考数量：2 支
- 画布：1080×1920
- 帧率：30fps
- 时长：约 7.38 秒

## 冻结结构

1. 顶部：城市 + 强提醒标题。
2. 标题下方：发布主体与本次开放内容。
3. 中部：高对比黄底核心卖点卡。
4. 前半段：价格/价值条和课程内容；参考片 2 不额外显示“课程设置”标签。
5. 后半段：`适合人群` 标签、人群与覆盖区域。
6. 末尾：可选单一 CTA；像素复刻默认不显示。

## v2 像素基线

以第二支参考片作为主像素基线，第一支用于校验共同的信息层级。坐标基于
1080×1920 画布：

| 元素 | top | 字号/尺寸 |
|------|-----|-----------|
| 主标题 | 276 | 102px，长标题自动降字号 |
| 通知来源 | 标题下 21px | 56px |
| 开放内容 | 再下 4px | 66px，白字红描边 |
| 黄底卖点卡 | 602 | 732×244，66px |
| 价格/价值条 | 902 | 58px，仅课程阶段显示 |
| 课程正文 | 1064 | 56px，无额外“课程设置”标签 |
| 适合人群标签 | 906 | 60px |
| 适合人群正文 | 1064 | 56px |
| 覆盖区域 | 1360 | 56px |

新闻通知模板默认使用 `NotoSansHans-Bold.otf` 粗黑体，不复用课程混剪模板的
新青年体比例。位置和字号集中在 `NEWS_NOTICE_TEMPLATE.layout`，不得在组件中
另设第二套数值。

## 文案规则

- 主标题写用户动作或机会，不写技术实现。
- 发布主体必须真实，不使用未经核实的“官方发布”“最新通知”等表述。
- 黄卡最多两行，每行只承担一个卖点。
- 课程、人群和区域分别承担不同信息角色，不重复主标题。
- 如果启用 CTA，只保留一个去向。

## 动效规则

- 只使用 `useCurrentFrame()`、`interpolate()`、`spring()` 驱动动画。
- 顶部标题和黄卡全程保留，正文在约 4.2 秒处切换。
- 动效服务于信息出现顺序，不使用持续抖动或高频闪烁。

## 首帧封面规则

- 抖音默认使用视频第 0 帧作为封面，因此第 0 帧不得使用尚未完成的入场动画。
- `NEWS_NOTICE_TEMPLATE.meta.coverFrame` 指向信息量最大且排版稳定的取样帧，当前为第 30 帧。
- 渲染时只在第 0 帧覆盖该取样帧；第 1 帧必须恢复原始动画和音频时间轴。
- 封面优先级为：城市/主钩子 → 开放内容 → 核心卖点 → 价格价值 → 课程范围。

## 验收

```text
□ 第 0 帧：标题、发布主体、开放内容、黄卡、价格和课程范围完整可读
□ 第 1 帧：恢复正常入场动画，无额外静帧停顿
□ 0.5 秒：标题、发布主体、开放内容和黄卡完整可读
□ 2.5 秒：课程设置与课程列表完整可读
□ 5.0 秒：适合人群与覆盖区域完整可读
□ 末尾：正文无突然截断；启用 CTA 时必须完整可见
□ 无黑帧、文字溢出、重复信息或错误配音
□ 音轨来源与参考素材有溯源记录
```
