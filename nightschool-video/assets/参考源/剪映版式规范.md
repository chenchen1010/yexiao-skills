## 坐标系说明

剪映使用**归一化比例坐标**，坐标指向**元素中心点**，与画布分辨率无关：
- 画面中心 = (0, 0)
- X: -1（左边缘）→ 0（中心）→ 1（右边缘）
- Y: -1（底部）→ 0（中心）→ 1（顶部）
- 坐标由 `clip.transform.x / y` 字段定义
- 每个元素还有 `clip.scale.x / y` 缩放系数（影响实际渲染大小）
- 字号单位是剪映内部单位，非像素（基准换算: size × 3.75 ≈ px @ 1080 宽度）
- 描边宽度 `0.08` 对应剪映 UI 中约 8% 粗度

### 转换为 CSS（分辨率无关）

```
CSS left = (1 + x) / 2 × 100%
CSS top  = (1 - y) / 2 × 100%
配合 transform: translate(-50%, -50%) 实现中心定位

字号 px = 剪映size × 3.75 × scale × (canvasWidth / 1080)
```
